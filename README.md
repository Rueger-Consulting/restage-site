# ReStage – project page

Public landing page for **ReStage**, a keyboard-first flow editor for IBM DataStage on Cloud Pak for Data and IBM Cloud: *DataStage, the way it should have been.*

The page is a single self-contained file (`index.html`, English and German) and is published with GitHub Pages from the `main` branch.

The editor itself is developed by Rueger Consulting in a separate, private repository.
